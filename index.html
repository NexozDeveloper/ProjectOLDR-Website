Questions, answered.

Windows says “Windows protected your PC”. Is that normal?

Windows shows this for installers it does not recognise yet. If you downloaded ProjectOLDR from this page, click More info, then Run anyway.

The installer asks for .NET. What do I do?

Install the .NET runtime the message points you to, then run the installer again.

How do I uninstall ProjectOLDR?

Open Windows Settings, go to Apps, find ProjectOLDR in the list and click Uninstall.

Does it work on macOS or Linux?

No. ProjectOLDR is built for Windows only we will work for other version soon were sorry MacOS Users and Linux Users.
